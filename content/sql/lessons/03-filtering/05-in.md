`IN` checks a column against a list of allowed values in one go.

## Context
It is shorthand for a chain of `OR` comparisons on the same column, and it stays readable as the list grows.

```sql
SELECT name, location FROM departments WHERE location IN ('Mumbai', 'Pune');
```

## Task
Return the `name` and `country` of users from India, France, or Spain.

## Hint
- List the three countries inside `IN (...)`, each in quotes and separated by commas.

## Solution
```sql
SELECT name, country FROM users WHERE country IN ('India', 'France', 'Spain');
```
