`OR` joins two conditions, and a row needs only one of them to be true.

## Context
Use it for alternatives that `AND` cannot express. When you mix `AND` with `OR`, add parentheses to control the grouping.

```sql
SELECT name, category_id FROM products WHERE category_id = 2 OR category_id = 5;
```

## Task
Return the `name` and `country` of users from the USA or Japan.

## Hint
- Write two equality conditions on `country` joined by `OR`.

## Solution
```sql
SELECT name, country FROM users WHERE country = 'USA' OR country = 'Japan';
```
